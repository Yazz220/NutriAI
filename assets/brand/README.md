# Nosh runtime brand assets

These application-ready files come from the canonical masters in `brand/masters/`.

Run `npm run brand:generate` after changing a master. Do not edit generated PNGs or synchronized SVGs directly.

- `platform/` contains Expo icons, adaptive icon layers, splash artwork, and the favicon.
- `marks/` contains SVG symbols, wordmarks, and lockups for product use.
- `characters/` contains the canonical Nosh expression states.
