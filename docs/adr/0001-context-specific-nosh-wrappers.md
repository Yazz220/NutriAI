# Use one collection-aware Folio with context-specific wrappers

Folio uses one assistant identity, shared collection access, and future shared memory, but each entry point presents a wrapper suited to its active job. We rejected both a universal ChatGPT-style input and separate assistant identities because the first hides task state and commitments while the second breaks continuity. Active context supplies focus rather than an access boundary, conversation handles reasoning, and guided UI handles commitments.
