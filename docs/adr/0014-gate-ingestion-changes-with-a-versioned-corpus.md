# Gate ingestion changes with a versioned corpus

Nosh maintains one provider-neutral, versioned ingestion corpus covering URL, text, image, video, and audio evidence. Human-verified recipe facts and evidence outcomes are the stable contract; model and provider names are run metadata. Every automated release case must pass, every modality must be represented, and false recipe acceptance or rejection blocks a candidate change. Hard cases without stable or properly licensed fixtures remain explicit diagnostic cases until they can be automated. Model, provider, prompt, parser, transcription, and normalization changes must be compared against the unchanged corpus before release, and sanitized production corrections should become regression cases.
