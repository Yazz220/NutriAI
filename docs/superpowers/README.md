# Historical plans and research

Everything in this directory is a dated record. These files explain earlier product decisions, experiments, and implementation sequences. They are not current instructions.

Several records describe systems that no longer exist:

- a blocking recipe review and approval flow;
- provisional or pending cookbook pages;
- a direct conversational import pipeline;
- live typesetter pages with a separate artwork layer;
- an in-reader table of contents.

For current work, use `CONTEXT.md`, `docs/PRODUCT_FLOW.md`, `docs/ARCHITECTURE.md`, `docs/DATABASE.md`, and accepted ADRs. [ADR 0002](../adr/0002-single-capture-and-complete-page-generation.md) supersedes every capture and image-generation recommendation here when they conflict.
