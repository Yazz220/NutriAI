# Supplied references

The files in `supplied/` are the original raster references provided by the brand owner. They are preserved without resizing, recoloring, compression, or metadata changes.

Two exact duplicates were excluded:

- The supplied image numbered 19 duplicates `12-brand-system-board.png`.
- The supplied image numbered 20 duplicates `14-brand-guidelines-board.png`.

Reference boards communicate intent and presentation. They are not production masters. Use the SVG files in `../masters/` for implementation and exports.
